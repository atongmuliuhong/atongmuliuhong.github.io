律师做AI助手，为什么我选择了自己造一个？——LawyerBuddy 桌面法律AI助手发布

一句话结论：你想找个 AI 帮手。但试了一圈——ChatGPT 聊完就忘，下次问同一个案子它记不住；Copilot 只会写代码；某个“法律AI”网站要你把案卷传上去，隐私怎么办。

你是不是也遇到过这些事

我是一名执业律师。过去半年我一直在找一个能真正帮上忙的 AI 助手，结果发现：现成的都不够用。

于是我自己造了一个。

这是什么

LawyerBuddy，一个开源的桌面法律 AI 助手，今天正式发布。

它底层是清华大学 THUNLP 实验室、面壁智能和 OpenBMB 联合研发的 AI Agent 操作系统——以「工作舱（WorkSpace）」为基本单位，每个案子一个独立空间，文件、记忆、技能全部隔离。多案并行互不干扰，换一个案子不会串到另一个案子的记忆。

但光有通用能力不够。律师的工作有它自己的规矩。

为律师做的四个改变

一、案件材料工作区：一键建好 9 大标准目录

点一下按钮，自动创建起诉状、证据、文书、判决、法规、案例、合同、函件、其他——九个子目录，和律所实际的案卷结构一模一样。

进入案件材料 Tab，目录树默认展开。右侧预览面板支持 Markdown、PDF、HTML、Excel、Word、PPT 内联预览，不用来回切窗口。

二、法律技能市场：集成开源法律技能库

内置 THUYRan/Legal-Skills-Chinese 开源法律技能库，涵盖法律检索、文书生成、证据审查、案例比对等常用技能。

你也可以通过链接导入技能——把 SKILL.md 的 URL 或 GitHub 地址发给它，自动下载安装。

三、白盒记忆：AI 记错了能定位到哪一条

大多数 AI 助手的“记忆”是个黑箱。LawyerBuddy 的记忆是白盒的——你可以看到每一条记忆、修改它、删除它。

AI 记错了某个法条，你不用重开会话，直接定位到那条记忆改掉就行。

四、长任务续跑：2000 条交互消息不是问题

LawyerBuddy 2.0（2026.10.15 发布）支持一键安装和可视化配置。长任务稳定续跑，2000 条交互消息不中断。

你今天开一个会话写完起诉状，明天接着同一个会话继续改——AI 记得住你昨天做了什么。

它不是什么

  • 不是聊天机器人。它是一个能操作文件系统、能调用工具、能跑代码、能查法律数据库的 Agent。
  • 不是 SaaS。数据不上传到任何第三方服务器，所有记忆和文件都在你本地。
  • 不是黑盒。记忆、技能、配置全部可查看、可修改、可导出。

怎么用

一键安装（推荐，macOS / Linux）：

```bash curl -fsSL https://raw.githubusercontent.com/atongmuliuhong/LawyerBuddy/main/install.sh | bash ```

安装完成后运行 `lawyerbuddy`，在 http://localhost:3001 打开。

Docker：

```bash docker compose up -d --build ```

源码安装： 见仓库 `README_SOURCE_INSTALL.md`，支持 macOS / Linux / Windows (WSL2)。

国内网络下载慢的话，可以指定镜像：

```bash curl -fsSL https://raw.githubusercontent.com/atongmuliuhong/LawyerBuddy/main/install.sh | \ LAWYERBUDDY_NODE_DIST_MIRROR=https://npmmirror.com/mirrors/node \ NPM_CONFIG_REGISTRY=https://registry.npmmirror.com bash ```

模型配置支持 OpenAI、Gemini、Ollama 本地模型等多种后端。你也可以用 DeepSeek、Qwen 等国产模型。

我为什么做这个

去年我花了很多时间在“让 AI 帮我写文书”上，但总差一口气——AI 记不住案子的上下文，整理好的证据目录下次就找不到了，同一个问题问第二遍它又从头开始解释。

后来我发现，问题不在模型不够聪明，而在没有一个真正为法律工作设计的操作系统。

LawyerBuddy 就是这个尝试。它不是什么颠覆性创新，但每一个细节都是从律师的实际工作流里长出来的：案件目录结构、法律技能库、白盒记忆、长任务续跑。

现在可以做什么

  • 去 GitHub 给个 Star：https://github.com/atongmuliuhong/LawyerBuddy
  • 克隆下来试一试：`git clone https://github.com/atongmuliuhong/LawyerBuddy.git`
  • 提 Issue / PR：我们欢迎所有法律同行加入

这个项目还在早期阶段。案件材料工作区的交互、法律技能库的覆盖面、桌面端的体验——还有很多可以打磨的地方。

如果你也觉得“律师需要一个自己的 AI 助手”，欢迎来试。
